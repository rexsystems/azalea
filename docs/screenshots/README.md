# Azalea screenshot gallery

79 screenshots of the desktop application and self-hosted web dashboard. Click any image to open the original PNG.

Captured on the `dev` branch at `9248184`, with the sync plan type correction applied. Desktop captures are 1440 × 1000; web captures use the same viewport and include the full page when it scrolls. Browser controls and the surrounding desktop are excluded.

The desktop frontend was rendered in an isolated Chromium session with mocked Tauri IPC. The web dashboard used mocked API responses. Hosts, accounts, public-key examples, files, terminal output, storage figures, and connection states are demonstration data. No live SSH, SFTP, cloud login, AI request, or server update was performed for these images. Native operating-system file pickers and detached OS windows are outside this gallery.

The web root redirects to sign-in; `/pending` redirects to Account and `/admin/pending` redirects to the admin overview, so they do not have separate screenshots.
